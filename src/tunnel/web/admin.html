NODE SETTINGS

节点设置

房间与带宽容量

家庭宽带和云服务器标注的 Mbps 均除以 8 才是 MB/s；例如 8 Mbps = 1 MB/s。这里 1 MB = 1,000,000 字节，请填写留给联机的实际出口带宽。

原版玩家没有固定带宽值。默认 0.128 MB/s/访客为可调整的预算假设，额外计入 15% 协议开销，并保留 35% 空闲。首次进入、新区块探索可能远超平均值，请结合视距、模组与实测调整。

保存后全节点、每个房间都会拒绝超额新访客，现有玩家不被踢出。房主占一个房间席位。带宽填 0 暂不启用带宽接纳限制；此设置不提供网络限速，也不保证 TPS 或延迟。
